05 wordmark

light · logo/commonplace.svg
dark · logo/commonplace-dark.svg
mark · logo/mark.svg · favicon.svg follows the system theme
mark, dark

A · the cursor. Picked. The name set in Plex Mono, and a block cursor at x-height in red. It says CLI without a window frame, and it says the book is never finished: there is always a next line. One glyph to remember, works at 16px.

B · the bookplate. cp in a hairline square, the name in Plex Sans. Closest to the heritage, and the best mark for a sticker. Passed: the sans wordmark reads as a company, and a boxed monogram is what every SaaS ships.

C · the rows. Three snapshot rows, the newest in red. Most literal about the data. Passed: at small sizes it is a hamburger menu, and the system already has rows everywhere; the logo did not need to be one too.

06 motion

follows state
Things move when something happened: a snapshot landed, a row appeared, a command finished. Never on a timer, never on scroll position.
120 · 200 · 320 ms
Hover and color, 120. Enter and reveal, 200. Layout and diagram wires, 320. One curve: cubic-bezier(.2,.7,.2,1).
typed, not faded
Terminal lines appear whole, in order, like real output. The cursor blinks at 1s in steps. Reduced motion stops it.
numbers are real
A counter counts to a number that exists in the archive. No made-up stats, no infinite tickers.
